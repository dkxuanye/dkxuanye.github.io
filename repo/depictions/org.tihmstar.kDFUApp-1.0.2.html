kDFUApp

在受支持的 32 位设备上一键进入 kDFU 模式

kDFUApp 提供了一种简单的方式进入 kDFU 模式：打开需要的开关后按下按钮即可。它主要面向仍在使用 32 位 A5/A6 等老设备、并需要 kDFU 流程的用户。

适合人群

适合明确知道自己为什么需要 kDFU 模式，并了解旧设备固件与刷写流程的用户。

风险提示

kDFU 属于低层刷写流程，错误的设备判断或操作顺序可能导致流程失败甚至设备无法正常启动。NOT COMPATIBLE WITH 64BIT DEVICES！不要在 64 位设备上使用本包。

兼容说明

支持范围：当前包依赖 `openssl`、`libcrippy-1.0.0`、`libpartialzip-1.0.0`、`curl`、`kloader` 与 `firmware (>= 6.0)`。上游声明兼容 iPhone3,1 / iPhone3,2 / iPhone3,3 / iPhone4,1 / iPhone5,1 / iPhone5,2 / iPhone5,4、iPad2,1 / iPad2,2 / iPad2,3 / iPad3,1 / iPad3,3。

使用条件：仅支持 32 位设备，不支持任何 64 位设备。本源仅镜像主包，`libcrippy`、`libpartialzip`、`kloader` 等传递依赖需要由用户现有的软件源提供。

使用提示

  • 先确认设备型号在支持列表内，且不属于任何 64 位设备。
  • 确认 `openssl`、`libcrippy-1.0.0`、`libpartialzip-1.0.0`、`curl`、`kloader` 等依赖已经可用。
  • 按需打开开关后再按下按钮进入 kDFU，不要在未知状态下反复尝试。
