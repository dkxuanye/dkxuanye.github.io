MiniBindFS

bindfs 文件夹绑定挂载 CLI,支持开机自动重挂

MiniBindFS 将系统只读目录(如 /System/Library/Fonts)复制到越狱根可写区后,用 XNU 内核 bindfs 只读绑定挂载回原路径,实现「改写只读系统目录」。支持开机自动重挂、动态 jbroot 探测、最小 entitlements 与多层安全守卫。

适合人群

面向 Relaxin/roothide 系 arm64e 越狱用户,需要修改系统字体等只读目录的场景。

风险提示

插件以 root 权限运行并短暂借用内核凭证;MNT_FORCE 强制卸载被系统进程占用的目录(如字体目录)实测可致字体显示不全、严重时触发越狱安全模式。请勿直接卸载系统占用目录,恢复原始字体请使用「清空配置 + 重启用户空间」方式。挂载本身为只读,不会写入系统。

兼容说明

支持范围：已验证:Relaxin 越狱 iOS 17.0-17.3.1,arm64e(iPhone 13 Pro Max 实测)。包架构 iphoneos-arm64e,依赖 firmware (>= 15.0)。

使用条件：设备需安装 plutil(apt install plutil);Dopamine 系与 checkm8 roothide 不可安装此包(架构与 vroot 语义差异)。

使用提示

  • 挂载:mount_bindfs /System/Library/Fonts(首次会全量复制目录)。
  • 开机自动挂载:mount_bindfs -s /System/Library/Fonts;查看 mount_bindfs -l。
  • 改字体:用 Filza 编辑 /var/jb/bindfs/System/Library/Fonts 副本,即时生效。
  • 恢复原始字体:先 mount_bindfs -s 清空配置,再 launchctl reboot userspace;切勿直接卸载系统占用目录。
