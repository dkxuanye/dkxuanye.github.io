MiniBindFS

bindfs 文件夹绑定挂载 CLI,支持 Relaxin 与 Dopamine 3.0

MiniBindFS 将系统只读目录(如 /System/Library/Fonts)复制到越狱根可写区后,用 XNU 内核 bindfs 只读绑定挂载回原路径,实现「改写只读系统目录」。支持开机自动重挂、双架构变体、最小 entitlements 与多层安全守卫。

适合人群

面向熟悉越狱环境与 root 操作的 Relaxin arm64e、Dopamine 3.0 arm64 用户,需要修改系统字体等只读目录的场景。

风险提示

插件以 root 权限运行并短暂借用内核凭证。工具不再对 EBUSY 自动执行 MNT_FORCE 强制卸载;系统占用目录卸载可能失败,请勿直接卸载字体等关键目录。恢复原始状态请先执行「mount_bindfs -s」清空配置,再整机重启;用户空间重启不会清除内核 bindfs 挂载。挂载点为只读,但误配置仍可能影响系统进程。

兼容说明

支持范围：发布两个独立变体:iphoneos-arm64e 面向 Relaxin;iphoneos-arm64 面向 Dopamine 3.0。Dopamine 3.0 / iOS 17.0 / iPhone 13 Pro Max 已实测;Relaxin 版 0.1.2 安全修复后尚未重新真机重测。

使用条件：设备需安装 plutil(apt install plutil),以 root 执行。真 roothide(RootHide 随机 jbroot、无 /var/jb)与 rootful 越狱未验证,不声称支持。

使用提示

  • 挂载:mount_bindfs /System/Library/Fonts(首次会全量复制目录)。
  • 开机自动挂载:mount_bindfs -s /System/Library/Fonts;查看 mount_bindfs -l。
  • 改字体:用 Filza 编辑 /var/jb/bindfs/System/Library/Fonts 副本,即时生效。
  • 恢复原始字体:先 mount_bindfs -s 清空配置,再整机重启;launchctl reboot userspace 不会清除内核挂载。
  • 请按越狱环境选择对应架构 deb,不要在未验证环境混用两个变体。
