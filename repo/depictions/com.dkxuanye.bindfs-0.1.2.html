MiniBindFS

越狱后修改系统字体和资源

MiniBindFS 会先复制一份系统目录,再把副本挂回原位置。这样可以修改系统字体或其他资源,而不直接覆盖原始文件。

适合人群

适合已经完成越狱,想修改系统字体或测试系统资源的用户。

风险提示

这是 Root 工具,使用前请先备份。不要直接操作整个系统目录,也不要强制卸载字体等关键目录。出现异常时,先执行 mount_bindfs -s,再完整重启设备。

兼容说明

支持范围：Dopamine 3.0 / iOS 17.0 已在 iPhone 13 Pro Max 上测试。Relaxin 安装包已提供,但 0.1.2 修复后还没有完成新一轮真机回归。RootHide/roothide 和 rootful 越狱未验证。

使用条件：从个人源安装即可。如果提示缺少 plutil,在终端执行 apt update && apt install plutil。

使用提示

  • 首次挂载:mount_bindfs /System/Library/Fonts。
  • 改字体:用 Filza 编辑 bindfs 副本,不要直接修改原路径。
  • 自动挂载:mount_bindfs -s /System/Library/Fonts;查看设置用 mount_bindfs -l。
  • 恢复原始状态:先 mount_bindfs -s,再完整重启设备。
